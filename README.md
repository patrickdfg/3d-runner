# SKY RUNNER — 3D 달리기 게임

Three.js로 만든 로우폴리 공중섬 스타일의 3레인 무한 달리기 게임입니다.

## 게임 실행
https://patrickdfg.github.io/3d-runner/

## 조작
- PC: ← / → 또는 A / D 레인 변경, Space / ↑ / W 점프, ↓ / S 슬라이딩, P / Esc 일시정지
- 모바일: 좌우 스와이프 레인 변경, 위로 스와이프 점프, 아래로 스와이프 슬라이딩
- 모바일 하단의 방향 버튼으로도 조작할 수 있습니다.

## 게임 규칙
- 바위는 점프로 피하고 높은 가로 장애물은 슬라이딩으로 통과합니다.
- 코인을 모으고 더 멀리 달려 최고 기록을 갱신합니다.
- 장애물과 충돌하면 게임 오버가 되며 즉시 재시작할 수 있습니다.
- 최고 기록은 브라우저의 localStorage에 저장됩니다.

## 기술
- Three.js ES 모듈 CDN, 별도 빌드 없는 정적 HTML
- GitHub Pages / main 브랜치 루트 배포
- 저사양 모바일 대응을 위해 픽셀 비율 제한, 간단한 로우폴리 지오메트리 사용

외부 Three.js CDN을 사용하므로 인터넷 연결이 필요합니다.
