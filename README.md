# 3D Runner — 1단계

Three.js 기반 3레인 달리기 게임의 기초 화면입니다.

## 실행
정적 HTTP 서버에서 `index.html`을 열거나 GitHub Pages에 배포합니다. Three.js 모듈을 CDN에서 가져오므로 인터넷 연결이 필요합니다.

## 조작
- PC: ←/→ 또는 A/D 이동, Space/↑/W 점프
- 모바일: 좌우 스와이프 이동, 위로 스와이프 점프 또는 화면 버튼

## 범위
3D 장면, 도로, 조명, 캐릭터, 달리기 애니메이션, 이동 및 점프. 장애물·코인·점수는 후속 단계에서 구현합니다.
